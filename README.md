
## 1.72 SpaceARK portable embeds

Adds lightweight portable routes for SpaceARK:

- `/embed/tip.html`
- `/embed/merch.html`
- `/embed/player.html`
- `/embed/follow.html`

These intentionally wrap the existing noahgrove.com pages so existing payment buttons, merch logic, support scripts, sticky-player/listen page logic, and Firebot watcher integrations remain owned by the main website rather than being duplicated in SpaceARK.
